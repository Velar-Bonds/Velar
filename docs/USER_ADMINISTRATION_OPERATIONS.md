# Operación segura del directorio

Antes de un cambio masivo, filtrar y revisar la selección. El resultado de lote informa los IDs actualizados; si se requiere rehacer una operación, debe hacerse como una nueva petición para conservar una segunda entrada de auditoría.

No desactivar la propia cuenta administrativa: el backend lo rechaza. La reactivación debe efectuarla un administrador y queda auditada igual que la desactivación.
